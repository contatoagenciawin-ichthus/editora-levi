# Editora Levi

Projeto inicial da presença digital da Editora Levi.

## Escopo desta fase

- Home institucional concisa
- Destaque para as obras de Adilson Borges
- CTA de publicação editorial via WhatsApp
- Landing page de `A Prisão ou o Milhão`
- Estrutura preparada para checkout e entrega digital em uma etapa posterior do mesmo projeto

A loja completa, catálogo administrável e carrinho multiobra não fazem parte deste MVP.

## Ambiente

Copie `.env.example` para `.env.local` e configure:

```bash
NEXT_PUBLIC_SITE_URL=https://editoralevi.com.br
NEXT_PUBLIC_WHATSAPP_NUMBER=55DDDNUMERO
```

## Desenvolvimento

```bash
npm install
npm run dev
```
